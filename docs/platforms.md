API Documentation.
How to integrate your CRM with PF Expert 2.0 using the Enterprise API?

Please make sure to follow the steps below for assistance with generating a Bearer "JWT" Token.

- Steps to Generate the Bearer Token:

Send a POST request to:
[https://atlas.propertyfinder.com/v1/auth/token](https://atlas.propertyfinder.com/v1/auth/token)

Use the following in the body (replace with your real credentials):

{
"apiKey": "YOUR_API_KEY",
"apiSecret": "YOUR_API_SECRET"
}

In the "Authentication" tab of your tool, use No Auth or Basic Auth.

Once submitted, you’ll receive a Bearer (JWT) token.
Use this token to access the API by selecting "Bearer Token" in the Auth Type.
